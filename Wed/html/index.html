About ShieldDrop

ShieldDrop is an advanced desktop security utility engineered for absolute data confidentiality at rest. Built using Python Eel, HTML5/Bootstrap, and MySQL, it ensures that your private files remain completely inaccessible to unauthorized parties.

By utilizing local PBKDF2 key derivation and AES-256 encryption, ShieldDrop eliminates reliance on vulnerable public cloud storage providers, giving you full sovereign control over your digital footprint.
